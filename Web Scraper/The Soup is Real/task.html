Description

We now have a good deal of knowledge and experience, so let's put it all together and create our first real web scraper. Most of the time, people create parse-and-scrape programs to automate routine tasks of retrieving large amounts of data from a website. Let's imagine you're building a reading recommendation dataset. For that research, you'd need to have the details of highly rated books. For this task, we will use the “Books to Scrape" sandbox website. Each book's description should be saved to a separate .txt file named after the book's title.

Objectives

Create a program that takes the http://books.toscrape.com/catalogue/page-1.html URL and then goes over its source code searching for books. Detect the book's rating and the link to view the book details.

Save the product description of each book that has a "Five" star rating to a separate file named %book_title%.txt. When you save the file, replace the whitespaces in the name of the book with underscores and remove punctuation marks in the filename. Use string.punctuation to remove punctuation. Strip all trailing whitespaces in the description and title. For example, the book with the title "Sapiens: A Brief History of Humankind" should be saved to the file named Sapiens_A_Brief_History_of_Humankind.txt.

We need to inspect each book to find the tags that represent the book's contents. Here's a breakdown of what you need to do with the source HTML:

  • Find books: Each book on the webpage is enclosed within an <article> tag with the class "product_pod". So, to locate books, look for these tags.

  • Identify book rating (type): Within each <article>, the rating of the book is specified inside a <p> tag. This <p> tag has class names like "star-rating One", "star-rating Two", etc. We are looking for books with the class "star-rating Five". By targeting this class, we can extract only the highly-rated books.

  • Access book contents link: Each book has a link to its contents, which is inside an <a> tag nested inside an <h3> tag. This <a> tag contains the relative URL to the book in its href attribute, and the full, un-truncated title in its title attribute. By targeting this <a> tag, we can identify and extract the link leading to the complete book description.

  • Retrieve book description: After following the link to view a book, the description of the book is displayed. This content is found in a <p> tag immediately following a <div id="product_description"> tag. Save this content.

Make sure your output file is binary with the UTF-8 character encoding.

Keep in mind that while the above methods work for scraping this specific website, they might not work for another one. The way we scrape depends on how each website is built. Different websites use different tags, attributes, and even dynamic content loading methods.
