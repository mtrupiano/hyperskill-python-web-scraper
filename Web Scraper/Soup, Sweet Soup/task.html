Description

You've done an amazing job in the previous stage! Remember we mentioned retrieving large data? Let's improve our program by making it parse multiple site pages. To make it even more useful, let's also implement the opportunity to parse multiple book ratings at once.

Objectives

Improve your code so that the function can take two parameters from the user input: the number of site pages (an integer) and the book rating type (a string). The integer with the number of pages specifies the number of pages on which the program should look for the books.

Go to the http://books.toscrape.com/catalogue/page-1.html website and find out how to navigate between the pages. Your program will do this by dynamically changing the URL.

Create a directory named Page_N (where N is the page number corresponding to the current iteration) for each page. Search and collect all books page by page; filter all the books by the star rating type and put all the book descriptions that are found on the page with the matched rating into the directory Page_N. Mind that when the user enters some number, for example, 4, the program should search all pages up to that number and the respective folders (Page_1, Page_2, Page_3, Page_4) should be created.

Save the descriptions to separate .txt files. Keep the same processing of the titles for the filenames as in the previous stage. You can give users some feedback on completion, but it is not required.

If there are no books on the page that match the user's rating, your program should still create a folder, but in this case, the folder would be empty.
